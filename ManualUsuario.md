## Introducción

Bienvenido al manual de usuario de la aplicación Exregan. Esta aplicación ha sido desarrollada en Java y tiene una interfaz gráfica de usuario (GUI) que te permitirá analizar expresiones regulares, validar cadenas de prueba y la visualización de distintos gráficos,autómatas o tablas relacionadas a la regex indexada.

## Requisitos del Sistema

Para utilizar esta aplicación, necesitarás tener instalado en tu computadora:
- Sistema operativo: A su elección
- Procesador: Procesador 64 Bits
- RAM: 4 GB
- Al menos 200 MB de espacio libre en disco duro
- IDE: Idealmente Apache Netbeans o o el de su elección para correr la aplicación o directamente ejecutar el .exe
- Sistema operativo compatible con Java (por ejemplo, Windows, Linux o Mac OS)
- Java Development Kit (JDK) instalado en la computadora. La versión de JDK debe ser compatible con la versión de Java utilizada para desarrollar el programa.

## Instalación

1. Descarga el archivo .jar de la aplicación desde el repositorio.
2. Abre el archivo .jar utilizando Java en tu computadora.
3. La aplicación se abrirá automáticamente en tu escritorio.

## Interfaz de Usuario
![Interfaz Gráfica](https://github.com/akamariano/P1_OLCA_202101149/blob/main/UIEXREGAN.png)
La interfaz de usuario de la aplicación X se compone de loa aiguientes elementos:
1. Editor de Código: permite al usuario indexar desde cero siempre y cuando se respete el lenguaje de codificación un archivo con expresiones regulares para ser analizado.
2. Botón abrir: Permite al usuario el despliegue de un explorador de archivos para que peuda seleccionar un archivo existente para su análisis.
3. Botón Guardar Como: al modificar un archivo existente o crear uno desde cero permite al usuario explorar suacrhivos para seleccionar en que carpeta desea almacenar lo existente en el editor de código.
4. Botón Guardar: permite guardar un archivo con un nombre genérico o el nombre anteriormente existente si se abrió uno.
5.  Botón Crear autómata: permite al usuario la creación de los autómatas
6. Botón Analizar Entrada: permite al usuario analizar lo indexado en el editor de código, validando el lenguaje y verificando las cadenas de prueba con las regex
7. Grafica Seleccionada: permite el despliegue de cualquier grafo seleccionado
8. Buscador De archivos: permite buscar entre las distintas carpetas de los gráficos para seleccionar el gráfico de interes y poder ser desplegado
